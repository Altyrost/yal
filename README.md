# Yet Another Launcher

Built with QML and Quickshell.

`yal` supports multiple modes through simple plugins.

Switch modes by typing a `!bang` followed by a space.
Use `!?` to open the bangs plugin and see the list of available bangs.

A few plugins are included (for now) to show what the launcher can do.

Plugins can also display content in panels around the main input bar. 
This is demonstrated in the `demo` plugin. 
Use the arrow keys to expand or collapse the panels.

This project is still very early, so expect bugs.
